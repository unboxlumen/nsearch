4 · 暗色模式

背景压暗为 #121212、表面 #1E1E1E，描边收敛到 #2C2C2E，文字提亮到 #FAFAFA， 状态色再提亮一档（绿 #34C77B、红 #E66A6A、琥珀 #E0A23A）。 单一品牌色 #007DFF 全程不变；图标 fillColor 用 ?attr/colorText 自动切换。

5 · 自检清单（对照 UI_DESIGN_GUIDE.md §10）

✓ 屏幕四周 16dp 外边距，非贴边
✓ 列表行触控区满宽、内容 16dp 内边距、图标统一 24dp
✓ 卡片 elevation = 0 + 1dp 描边 + 16dp 圆角
✓ 列表项 12dp 间距 + 末项补 24dp 底距
✓ 全部使用 Material 原生组件（MaterialCardView / Chip / LinearProgressIndicator / BottomSheet）
✓ 主色单一（#007DFF），层级靠留白与对比建立
✓ 动效 ≤ 300ms、统一 AccelerateDecelerateInterpolator、尊重 reduced-motion
✓ 列表具备「有数据 / 空 / 错误 / 索引中」四态
✓ 触控目标 ≥ 48dp、对比度 WCAG AA
✓ 图标矢量规范（1024 视口 / 85.3 线宽 / ?attr/colorText 取色）
✓ 暗色模式真实落地（非简单反色）
