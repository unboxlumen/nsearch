4 · 文件类型矩阵（含 DOC / PPT）

FileType 覆盖 TXT / MD / CSV / PDF / XLS（xls+xlsx）/ DOC（doc+docx）/ PPT（ppt+pptx）共 7 种。下面是类型矩阵（影响设置页“Indexed file types”多选与抽取器）：

类型扩展名抽取方案状态
TXTtxtUTF-8 直接读已有
MDmdUTF-8 直接读已有
CSVcsvUTF-8 直接读已有
PDFpdfPDFBox（桌面版，逐文件降级）已有（Android 有限）
XLSxls / xlsxjxl（xls）+ 自研 zip+XML（xlsx）已有
DOCdoc / docx / dotdocx 自研 zip+XML 抽取；.doc / .dot 用 Apache POI HWPF 抽取已有
PPTppt / pptx / pps / potpptx 自研 zip+XML 抽取；.ppt / .pps / .pot 用 Apache POI HSLF 抽取已有
现状： docx / pptx 用自研 zip+XML 轻量抽取器；老格式 .doc / .ppt 已引入 Apache POI（poi + poi-scratchpad，HWPF / HSLF）做正文抽取，抽取器对解析/运行时异常做了 try/catch 兜底，单文件失败仅降级为“文件名命中”，不会中断索引。 代价：release 包从 ~17MB 增至约 22MB（POI 核心 + scratchpad + commons-io，R8 已大幅裁剪）。 DOC/PPT 已加入设置页默认启用的 7 种类型。
